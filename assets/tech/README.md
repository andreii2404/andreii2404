# Technology icons

The logo artwork is from [Devicon](https://github.com/devicons/devicon), distributed under the [MIT license](LICENSE). The marks remain the property of their respective owners; no affiliation or endorsement is implied.

Flutter, Dart, React, JavaScript, HTML5, CSS3, Unity, C#, Supabase, PostgreSQL, Git, and GitHub use the Devicon SVG assets already retained in the personal portfolio. Next.js and TypeScript use the original SVGs from the official Devicon repository, retrieved on October 29, 2026:

- [Next.js original](https://github.com/devicons/devicon/blob/master/icons/nextjs/nextjs-original.svg)
- [TypeScript original](https://github.com/devicons/devicon/blob/master/icons/typescript/typescript-original.svg)
- [All Devicon icons](https://github.com/devicons/devicon/tree/master/icons)

Each local SVG adds a dark tile and a readable technology label. GitHub and Unity use lighter monochrome fills for contrast; Next.js adds a subtle circle outline. Colored logos retain their source colors. The profile loads these local assets without a third-party badge service.
